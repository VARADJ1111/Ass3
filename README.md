# Gradefolio — Student Result Management System

A minimal, interactive college project built with HTML, CSS, and JavaScript.

## Features
- Add student details and marks for five subjects
- Live total and percentage calculation
- Dynamic student register
- Search and sort student records
- Edit and delete records
- Automatic class topper identification
- Dashboard statistics: student count, class average, and pass rate
- Export records to CSV
- Browser local storage persistence
- Responsive layout

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Click **Load demo data** to explore sample records, or enter a new student.

## Notes
- Each subject is marked out of 100; total is out of 500.
- A student passes when every subject mark is at least 35.
- Data is stored in the current browser using local storage. It is not synced to other devices.
- This is a frontend-only project; it does not include a server or SQL database.
